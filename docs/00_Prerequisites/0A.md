# Group 0A: Python, NumPy, and Engineering Entry

## Group Overview

Samples, tensor shapes, cumulative metrics, and file paths each need a different form of expression. This group first examines containers and function inputs, then handles array dimensions, and afterward distinguishes an object's internal state from the configuration and files of a single run.

![0A reading route for data, arrays, objects, and run files](../public/00_Prerequisites/0a_language_data_map.svg)

## Learning Path

### Recommended Order

Read in the order 01 → 02 → 03 → 04. If you are familiar with Python and NumPy, you can first run the verification code on each page and then trace back through the failures; 03 handles an object's internal state, and 04 handles configuration and external files.

### Next Steps

Go to [0B Tensors and Autograd](./0B.md) and continue examining PyTorch tensor storage, layout, and gradients. Later, when you encounter shape problems, refer back to 02; when cumulative metrics are abnormal, refer back to 03; and for configuration and path problems, refer back to 04.
