This group puts the components of 2.1 back into a complete model structure and expands along three branches: model blocks and configuration, MoE capacity, and long-sequence memory. Mechanism pages first answer how the structure works, and project pages then fix real models and workloads to form quality–cost evidence.

## Mechanism Learning Path

- **Model block and audit:** 05 → 08. First confirm the residual mainline and component positions, then check the configuration declarations, parameter identity, and actual modules.
- **MoE capacity:** 05 → 06 → 07. The router first produces candidates, capacity determines the admitted set, and load feedback then affects training stability; multi-GPU dispatch and collective communication are not expanded again in this group.
- **Attention representation and access:** 04 → ARCH-MLA; 03 → 44. The former changes what state is saved, and the latter changes which positions in the history are visible.
- **Recurrence and hybrid memory:** 44 → 45 → ARCH-HYBRID-MEMORY. First understand the limited access range, then compare fixed state with explicit history, and finally enter hierarchical hybridization.
