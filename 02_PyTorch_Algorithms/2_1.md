# 2.1 Decoder Components and Attention Basics

This group establishes the component chain of a modern decoder: how text becomes model state, how normalization and the gated feed-forward network change channel representations, how position enters queries and keys, and how multi-head attention organizes query heads and KV heads. Here the input, output, and state semantics of the components are fixed first; 2.2 then discusses model blocks, MoE, and long-sequence memory structures.

## Reading Order

Read 00 first to establish the input state and tensor contracts. 01 and 02 are two parallel channels inside the model block; 03 is the positional prerequisite for attention, after which 04 connects query heads, KV heads, and historical state. When you need to continue comparing latent KV representations, you should first enter [ARCH-MLA](./ARCH-MLA_Multihead_Latent_Attention.ipynb) in 2.2, and then enter project 71 for real-model and backend evidence.

