# Group 1A: Numerics and Scale

This group turns a model configuration into a reviewable capacity and compute budget.

## Group Goal

First convert parameters and training-state storage according to the data type, then estimate the parameter count and FLOPs from the model structure; the quantization and MoE branches explain representation cost and active compute respectively. When computing, record the model structure, data type, and state composition; when verifying performance, also fix the input shape, batch, and execution environment, and measure time, memory, and numerical error.
