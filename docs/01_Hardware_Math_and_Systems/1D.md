# Group 1D: Execution Models, Asynchrony and Operator Mapping

This group answers how a program enters the actual execution units.

## Group Goal

First compare the compute and transfer costs of leaving a task on the host or migrating it to the device, then learn how frameworks, CUDA, or Triton organize execution. The execution-mapping branch checks data coverage, on-chip resources, and boundaries; the asynchronous-scheduling branch checks input readiness, queue order, and cross-queue dependencies. The CPU calculator gives the resource volume and completion time under the specified assumptions, and actual overlap still needs to be verified with an execution trace.

## Execution and Scheduling Paths
